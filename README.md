# MatchingGame
Matching Game- это простая игра. Она развивает память, внимательность и зрительное восприятие. Игра подходит для любого возраста: от детей трех лет до взрослых.
# Из чего состоит игра:
Главный и единственный элемент игры- это карточки.
Парность: Все карточки делятся на пары. На двух карточках изображен один и тот же рисунок.
Оформление: Оборотно-задняя сторона у всех карточек одинаковая. Лицевая сторона содержит разные изображения: животных, предметы, цифры или и тд.
# Суть и цель игры:
Суть игры- найти как можно больше одинаковых пар карточек, запоминая их расположение на столе.
Цель: Собрать больше пар, чем твои соперники, или очистить поле за минимальное время, если играешь один.
# Правила игры:
Выберите две карточки. Запомните значки на них.
Затем выберите следующую карточку, если она совпадает с одной из предыдущих, то выберете её.
Играйте, пока для всех карточек не будет найдена пара и они не будут открыты.
# Советы для победы:
Мысленно дели поле на зоны: Привязывай картинку к конкретному углу или ряду.
Не спеши: Сначала вспомни, где ты уже видел открытую картинку, и только потом переворачивай вторую карточку.
